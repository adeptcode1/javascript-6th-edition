Our Services

What We Do

We undertake projects of various sizes and depth. These projects engage various skillsets and technologies in their development. We have a foundation in building a web presence using the following technologies.

Hypertext Markup Language (HTML)
This is the written language formatting information on the internet. With this language, we organize information so that it is understandable by both humans and machines. Best practice organizes information independent of presentation. Our initial development is performed in this language.
Cascading Stylesheets (CSS)
Cascading Stylesheets are used to layout HTML documents in presentation form. This creates the visual structure that is rendered by the browser. We can create these with optimizations for devices of differing capabilities.
JavaScript
JavaScript can be used to perform various dynamic operations. This can be as simple as changing properties of HTML elements. It can be more complicated, creating objects that are generated interactively with server connections. JavaScript's are programs that are executed within the users browser.
Personal Hypertext Preprocessor (PHP)
PHP is a server-side scripting language. Programs are created in this language to operate on the server, generating dynamic content in HTML for the browser. It is one of the most popular server-side scripting languages.
Database Integration
Interacting with users can generate information that we want to save for their future use, or internal operations. Databases can be used to store information that is used to create dynamic content with various scripting languages.

Note that each project is different. HTML and CSS are utilized for creating a basic site, or organizing and presenting a more complicated site engaging various scripting technologies and databases. We analyze the needs of your site to develop content and features that may engage scripting technologies as required.
